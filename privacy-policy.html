AI HOT Notifier 隐私政策

最后更新：2026年9月17日

概述

AI HOT Notifier 是一款浏览器扩展，通过 aihot.news 的公开 API 获取 AI HOT 资讯并推送桌面通知。我们重视您的隐私，本扩展的设计原则是最小化数据使用。

数据收集

我们不收集任何用户个人数据。

本扩展：

  • 不收集、存储或传输任何个人身份信息
  • 不使用 Cookie 或追踪技术
  • 不包含任何分析或广告 SDK
  • 不与任何第三方共享数据

本地存储

扩展使用浏览器本地存储（包括 chrome.storage.local、chrome.storage.session 和 localStorage）保存以下数据，这些数据仅存在于您的设备上：

  • 用户偏好设置（主题、字体、轮询间隔等）
  • 资讯历史记录（标题、链接、来源、时间）
  • 已读状态标记
  • 特关规则及提醒状态
  • 阅读位置和界面缓存

这些数据完全保存在本地，不会上传到任何服务器。

弹窗性能日志仅保存在本次弹窗内存和浏览器控制台中，不会自动上传；点击“拷贝日志”时会写入本机剪贴板。

网络请求

扩展通过 GET 请求访问 aihot.news 的公开资讯 API，并可能使用 ETag 条件请求避免重复下载内容。请求不上传您的偏好、阅读记录、特关规则或本地日志。API 服务会收到正常网络连接所需的信息，例如 IP 地址。

点击资讯或品牌链接后，浏览器会打开对应网站；目标网站的数据处理适用其自身隐私政策。

权限说明

  • alarms：用于定时轮询
  • notifications：用于推送桌面通知
  • storage：用于本地保存设置和历史记录
  • host_permissions (https://aihot.news/*)：用于访问资讯 API

联系方式

如有隐私相关问题，请通过 Chrome Web Store 的支持渠道联系我们。
