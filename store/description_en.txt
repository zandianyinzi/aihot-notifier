Track AI frontier trends as it happens — instant desktop notifications, flexible themes, lightweight and unobtrusive.

Automatically tracks the latest AI updates and delivers desktop notifications, so you never miss what matters.

✦ Core Features

• Automatic monitoring for AI news with desktop notifications
• Click notifications or list items to jump directly to the source
• News list with title + summary; each item shows its source and local time (MM/DD HH:mm)
• Read/unread state persists across browser restarts
• Mark all as read in one click; unread items stand out by background and title brightness
• Category tags (Model / Product / Industry / Paper / Tips / Opinion) for quick scanning
• Watch rules: follow sources, authors or keywords; matches are pinned to the top and notified separately
• Watch-only mode: when on, the list shows only watch matches, the badge counts only their unread items, and desktop notifications cover only watch matches

✦ Personalization

• 4 carefully crafted themes: Obsidian Night / Dark Forest / Chrome Ink / Slate Cyan
• 3 font styles: System / Serif / Kai
• 5 font size levels: Small / Default / Large / Extra Large / Huge
• Position mode: Free Browse / Unread First
• Configurable polling interval: 2 / 5 / 15 / 30 / 60 minutes
• Configurable display range: 1 / 2 / 3 / 5 / 7 days (default: 1 day)

✦ Data Source

News curated from aihot.news, covering AI model releases, product updates, industry news, academic papers, usage tips and opinion. Preferences, cached news, and read state stay on your device; no user information is collected.
