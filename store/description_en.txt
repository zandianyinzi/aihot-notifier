Automatically tracks the latest AI updates and delivers desktop notifications, so you never miss what matters.

✦ Core Features

• Automatic monitoring for AI news with desktop notifications
• Click notifications or list items to jump directly to the source
• News list with title + summary, grouped by date with MM/DD labels
• Read/unread state persists across browser restarts
• Category tags (Model / Product / Industry / Paper / Tips) for quick scanning

• 4 carefully crafted themes: Obsidian Night / Dark Forest / Chrome Ink / Slate Cyan

• 5 font size levels: Small / Default / Large / Extra Large / Huge
• Position mode: Free Browse / Unread First

• Configurable display range: 1 / 2 / 3 / 5 days (default: 1 day)

News curated from aihot.news, covering AI model releases, product updates, industry news, academic papers, and usage tips. Preferences, cached news, and read state stay on your device; no user information is collected.
